# Lighter option: animated avatar instead of a face swap

If you want a cartoon/anime/3D character that copies your expressions
(instead of a realistic face swap), use an avatar app. They're lighter and very stable:

- **VTube Studio** (free on Steam/Mac): 2D anime-style avatars, has its own virtual camera.
- **Animaze** (free tier, Windows only): 2D/3D avatars, virtual camera built in.
- **Snap Camera-style filters**: Snap's "Snap Camera" is discontinued; OBS + face-filter plugins can replace it.

Same last step: pick the app's virtual camera (or OBS Virtual Camera) in Zoom or Chrome.
